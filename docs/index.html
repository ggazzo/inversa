Before you install

  • Connect the ESP32 board to your computer with a USB-C data cable (charge-only cables won't enumerate).
  • Click Install firmware and pick the serial port matching the device.
  • Web Serial erases and flashes the bootloader, partition table and application in a single ~30 s step.
  • After installing, configure WiFi either through the post-install wizard or via the web app over Bluetooth.

BrewPilot is open source — github.com/ggazzo/brewpilot. Binaries live in the latest release, signed with ECDSA P-256.
